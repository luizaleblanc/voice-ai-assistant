            <p>
                Este projeto consiste em uma interface web interativa desenvolvida para permitir conversas por voz com Inteligência Artificial. 
              A aplicação tem como objetivo principal capturar o áudio do usuário, transcrever a fala para texto através da API Whisper e utilizar esse contexto para 
              gerar respostas inteligentes via ChatGPT. O desenvolvimento foi focado em proporcionar uma experiência de usuário fluida, com tratamento robusto de permissões 
              de microfone, latência de rede e gestão de erros.
            </p>

            <h2>Protocolo de Uso e Testes</h2>
            <p>
            Protocolo de Uso e Testes
            Não acesse a aplicação diretamente pelo navegador interno de redes sociais (Instagram, TikTok, Facebook), pois eles frequentemente bloqueiam a captura de áudio.
            Caso abra o link por uma rede social, clique no menu de opções (três pontos) e selecione "Abrir no Navegador" ou "Abrir no Chrome/Safari".
            Utilize preferencialmente os navegadores Google Chrome (Android/Desktop) ou Safari (iOS) para garantir compatibilidade com a API de microfone.
            Certifique-se de conceder permissão de uso do microfone assim que o site solicitar.
            Se houver erro de permissão, verifique nas configurações de privacidade do seu sistema operacional (celular ou computador) se o navegador tem acesso liberado ao microfone.
            Aguarde a finalização das etapas de transcrição e processamento da IA antes de fechar ou recarregar a página.
            Para melhores resultados na transcrição, grave o áudio em ambientes com pouco ruído de fundo.
                    </p>
